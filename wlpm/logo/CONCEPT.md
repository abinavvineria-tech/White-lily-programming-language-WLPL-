# White Lily Package Manager — Logo Concept

## Concept

The WLPM logo is a minimalist white lily flower with petals gently falling,
representing growth, beauty, and the blooming of packages in a garden ecosystem.

## ASCII Logo

Used in terminal output:

```
      ❀
     / \
    /   \   ✿
   /  ❀  \
  /_______\
      ||
      ||
    \====/
     \__/
```

## Symbolic Mark

A single white lily flower represented as `❀` or a stylized "W" with a flower
integrated into the letterform.

## Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| White | `#FFFFFF` | Flower petals, highlights |
| Silver | `#C0C0C8` | Stems, subtle details |
| Soft Green | `#A8D5BA` | Leaves, growth accent |
| Crystal Glow | `#A8E6FF` | Magical sparkles, emphasis |
| Crystal Blue | `#C8E6F0` | Secondary accent |
| Crystal Dim | `#B0D4F0` | Muted details |

## Typography

- Primary: A clean sans-serif (Inter, SF Pro, or similar)
- Monospace: JetBrains Mono or Fira Code for terminal output
- Decorative: A gentle script font for "White Lily" branding

## Full Logo

```
❀  White Lily Package Manager  ❀
   magical package management
```

## Icon Sizes

- 16x16: Terminal icon, favicon
- 32x32: Application icon
- 64x64: Social media
- 128x128: Store listing
- 512x512: High-resolution branding

## Variations

1. **Full**: Logo + "White Lily Package Manager" text
2. **Compact**: "WLPM" with flower accent
3. **Icon-only**: Single flower `❀`
4. **Terminal**: ASCII art flower for CLI output
